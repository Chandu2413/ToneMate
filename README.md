# ToneMate AI Module

ToneMate is an AI-based fashion recommendation system that:
- Detects face from an image
- Identifies gender automatically
- Detects skin tone
- Recommends suitable dresses

## Technologies Used
- FastAPI
- TensorFlow (CNN)
- OpenCV
- MTCNN

## How to Run
pip install -r requirements.txt
uvicorn app:app --reload
